# VÉRTICE — instruções para agentes de código

Objetivo: construir um e-commerce conceitual premium para portfólio. Prioridade: qualidade visual, UX, responsividade e acessibilidade, antes de adicionar infraestrutura complexa.

- Stack: Next.js App Router + React + TypeScript + CSS customizado.
- Use o português brasileiro nas mensagens e preços em BRL.
- Preserve o tom editorial: preto, off-white, cinza mineral, tipografia com contraste.
- Não simule backend/checkout real como se estivesse conectado a serviços: mantenha o rótulo de demonstração.
- Não copie imagens diretamente do Pinterest; confirme licenças.
- Antes de alterações grandes, revise estrutura e mantenha componentes reutilizáveis.
- Valide `npm run typecheck`, `npm run lint` e `npm run build` se dependências estiverem disponíveis.
